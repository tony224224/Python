Создание и основы

Строка (str) — это неизменяемая последовательность символов.

Строки записываются в двойных или одинарных кавычках.

s1 = "Hello world"
s2 = 'Hello world'
s3 = str(123) # "123"

Строка является неизменяемой (immutable) структурой данных! Нельзя изменить отдельный символ по индексу.

Основные операции

К элементам строки можно обращаться так же, как к списку — по индексу.

Умножение строк:

s = 'hello' * 3
print(s) # hellohellohello

Анализ и проверки

Для проверки наличия подстроки используется оператор in:

print("lo" in "Hello") # True
isalpha()
Возвращает True, если строка состоит только из букв.
isdigit()
Возвращает True, если строка состоит только из цифр.
isnumeric()
Возвращает True, если строка является числом (включая дробные символы Юникода, но не float).
islower() / isupper()
Проверяет, находится ли строка в нижнем / верхнем регистре.
startswith(prefix)
Проверяет, начинается ли строка с указанного префикса.
endswith(suffix)
Проверяет, заканчивается ли строка указанным суффиксом.

Изменение регистра и очистка

Т.к. строки неизменяемы, эти методы возвращают новую строку.

upper()
Переводит строку в верхний регистр.
lower()
Переводит строку в нижний регистр.
strip([chars])
Удаляет пробельные символы (или указанные в chars) с обоих концов строки.
lstrip([chars]) / rstrip([chars])
Удаляет символы только слева (в начале) / только справа (в конце).
zfill(width)
Дополняет строку нулями слева до указанной длины.
print("42".zfill(5)) # 00042

Поиск и замена

find(sub, [start], [end])
Возвращает индекс первого вхождения подстроки sub. Если не найдено, возвращает -1.
count(sub, [start], [end])
Возвращает количество вхождений подстроки.
replace(old, new, [count])
Заменяет все (или count первых) вхождения old на new.

Пример замены (включая нерекурсивную замену)

s = "Hello World"
print(s.replace("World", "Python")) # Hello Python

# Замена удаляет вхождения, но не выполняет их повторно в уже замененном тексте
text = "AA"
# Если бы замена была рекурсивной или циклической, мы могли бы получить бесконечность или странный результат.
# Здесь каждое вхождение 'A' меняется на 'A A'.
print(text.replace("A", "A A")) # "A A A A" 
# Первая 'A' -> 'A A', Вторая 'A' -> 'A A'. Результат склеивается.

Разделение и объединение

split([sep], [maxsplit])
Разбивает строку на список подстрок по разделителю sep. По умолчанию — по пробелам.
text = "one two three"
print(text.split()) # ['one', 'two', 'three']

data = "12-05-2023"
print(data.split("-")) # ['12', '05', '2023']
join(iterable)
Объединяет список строк в одну строку, вставляя между ними текущую строку-разделитель.
words = ['John', 'Mary', 'Peter']
print(', '.join(words)) # John, Mary, Peter
